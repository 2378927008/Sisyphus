# Local Flow Windows UI 审查

## 范围

审查 Windows 主窗口的首页入口、录音主控、结果与历史、设置抽屉。目标是判断当前界面是否适合高频语音输入，并为 UI v3 重构确定优先级。

## 流程

1. **首页入口：较差**
   - 证据：[首页](01-home.jpg)
   - 语言、模型状态和安装刷新占据首屏，录音操作位于首屏下方。
   - 默认菜单栏、横向滚动条和过量空白削弱产品感。

2. **录音主控：较差**
   - 证据：[录音主控](02-record-control.jpg)
   - 巨大圆形按钮占据近半屏，却缺少紧凑的快捷键、波形和状态组合。
   - 状态信息与主控分离，视线移动距离过长。

3. **结果与历史：一般偏差**
   - 证据：[结果与历史](02-main-actions.jpg)
   - 最新结果区域在空状态下仍占用大量空间。
   - 历史被压缩到狭窄侧栏，复用操作不明确。

4. **设置抽屉：严重过载**
   - 证据：[设置上部](03-settings.jpg)、[高级下载地址](04-settings-lower.jpg)
   - 普通设置、模型安装、诊断、本地路径和下载镜像混在同一长页面。
   - 保存操作距离修改位置过远，高级技术字段没有渐进披露。

## 主要风险

- 日常主任务未成为首屏焦点。
- 页面级纵向和横向滚动降低操作效率。
- 模型与下载技术细节给普通用户造成错误的优先级暗示。
- 纯视觉截图无法验证键盘焦点顺序、读屏器语义、200% 缩放和真实录音状态。

## 建议

- 首页只保留语言、录音状态、最新结果和最近历史。
- 将录音入口改为紧凑命令条，并保留全局快捷键与 HUD 作为最快路径。
- 将设置分为常规、快捷键、模型与隐私、高级四组。
- 默认隐藏本地路径、下载镜像和安装日志。
- 使用熟悉图标、可见焦点和稳定尺寸，消除横向滚动。
